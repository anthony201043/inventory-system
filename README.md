# Inventory System

A Python-based inventory management system that manages products, stock levels, orders, prices, tax, and receipts.

## Features

- Stores product information
- Tracks product prices
- Tracks available stock
- Processes customer orders
- Checks product availability
- Checks available stock before processing orders
- Calculates tax
- Generates receipts

## Tools Used
- VS code
- Python
